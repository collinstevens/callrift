# Receiver context through inherited calls

Status: implementation integrated and all 22 changed corpus views reviewed. Forty snapshot files are updated, and the independent full-corpus repeat passes all 81 views. The complete scenario push hook remains pending.

An inherited helper previously lost the concrete containing instance. A call from sealed `Left.Entry` through `Base.Shared` could enter sibling `Right.Hook`. Independent fixtures reproduce this without compilation diagnostics. The graph now carries the receiver through calls on the same instance, including explicit base calls, reference casts, constructors, local functions, and possible callbacks. Fields, parameters, static intermediaries, delegate invocations, and user-defined conversions retain their own receiver boundaries. Closed generic receiver arguments constrain dispatch; open parameters remain conservative.

An invocation records receiver identity only when its containing-instance calls can depend on virtual dispatch. This preserves one shared inherited implementation when its behavior does not depend on the receiver type. A new sibling override does not invent an edit to an unchanged sealed caller. A dispatch whose sole remaining target is the original declaration has the same representation as that direct invocation. Public JSON symbol IDs continue to identify declarations.

File-local compiler metadata names depend on physical syntax-tree paths. Using those names in cross-revision invocation identities falsely marked identical source as changed. The type catalog now carries logical declaring-file identities for invocation comparison. Compiler type names remain available for matching within a compilation. The worker supplies logical type paths when rebuilding the combined dispatch map. Empty file-local classes and interfaces, nested types, generic arguments, and same-basename files in different directories have independent checks.

Receiver specializations share the existing bounds of 65,536 additional invocation states and 128 type nodes. Bound diagnostics and omissions remain explicit. A receiver-only stress fixture confirms that crossing the state bound does not invent changes in an unchanged caller. Cycle references point to the first active invocation of the same context.
