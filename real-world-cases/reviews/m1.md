All ten commands exit successfully; diagnostics describe partial source-only binding rather than a complete program model.

The `LICENSE` blob at every pinned after revision was checked: Serilog uses Apache-2.0 and CleanArchitecture uses MIT. Source remains in the external clone cache. These snapshots contain method labels, short conditions, and analysis diagnostics.

An accepted snapshot documents current behavior; it does not certify full semantic coverage. M3 should turn unresolved edges into reviewed changes where real references allow binding.
